---
title: "List tasks"
openapi: "GET /v1/tasks"
description: "Legacy task list (Admin → Task)."
---

Legacy task list (Admin → Task). `member_id` is the assignee. Create requires a name; an assignee must be an active member of the chapter.

**Required scope:** `tasks:read`

<ResponseExample>

  "data": [

      "name": "Book the hall",

      "createddate": "2026-09-01T00:00:00Z",
      "lastmodifieddate": null
    }
  ],

    "total": 1,
