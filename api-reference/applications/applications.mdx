---
title: "List membership applications"
openapi: "GET /v1/applications"
description: "Membership applications and renewals in the chapter, newest first."
---

Membership applications and renewals in the chapter, newest first. `status` is the workflow stage (for example `application_submitted`, `application_approved`, `renewal_declined`). Filter by `member_id` or `status`. Form answers are only returned on the single-application route.

**Required scope:** `applications:read`
