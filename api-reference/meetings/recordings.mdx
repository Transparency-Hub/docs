---
title: "List Meeting Recordings"
openapi: "GET /v1/meetings/{meeting_id}/recordings"
description: "Retrieve recording metadata for a meeting."
---

Retrieve recording metadata for a meeting. File links and transcripts are not available through the public API.

**Required scope:** `meetings:read`

```json 200
{
  "status": "success",
  "data": [

      "id": 8,
      "event_id": 11,

      "createddate": "2026-10-01T12:35:00Z"
    }
  ],
  "pagination": {
    "total": 1,

}
```
</ResponseExample>
