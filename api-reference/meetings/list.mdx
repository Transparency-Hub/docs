---
title: "List Meetings"
api: "GET /v1/meetings"
description: "Retrieve the chapter in-app meetings, newest start first."
---

Retrieve the chapter in-app meetings, newest start first. Filter by `from` / `to` on the start time. Room identifiers and join handles are never exposed.

**Required scope:** `meetings:read`

<ResponseExample>
```json 200
{
  "status": "success",
  "data": [
    {
      "id": 31,
      "event_id": 11,
      "title": "Annual General Meeting",

      "valid_from": "2026-10-01T09:45:00Z",
      "valid_until": "2026-10-01T12:30:00Z",
      "status": "scheduled",
      "provisioning_status": "ready",
      "createddate": "2026-09-14T08:00:00Z"
    }
  ],

    "total": 1,
    "offset": 0,
    "limit": 50
  }
}
```
</ResponseExample>
