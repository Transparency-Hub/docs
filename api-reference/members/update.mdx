---
title: "Update Member"
openapi: "PATCH /v1/members/{member_id}"
description: "Update a member's `title`, `firstname`, `lastname`, `country` or `profilepic`."
---

Update a member's `title`, `firstname`, `lastname`, `country` or `profilepic`. Email and password cannot be changed through the public API.

**Required scope:** `members:write`

<RequestExample>
```json Request
{
  "firstname": "Augusta"
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "status": "success",
  "data": {
    "id": 42,
    "title": "Mr",
    "firstname": "Ada",
    "lastname": "Lovelace",
    "email": "ada@example.org",
    "country": "NG",
    "profilepic": null,
    "chapter_id": 9,
    "role_id": null,
    "membership_type_id": 3,
    "status": "active",
    "is_new_user": false,
    "createddate": "2026-01-15T10:00:00Z",
    "lastmodifieddate": null
  }
}
```
</ResponseExample>
