---
title: "List Members"
api: "GET /v1/members"
description: "Retrieve a paginated list of the chapter's members."
---

Retrieve a paginated list of the chapter's members. Supports `search` (first name, last name or email) and `status` (`active` / `inactive`).

**Required scope:** `members:read`

<ResponseExample>
```json 200
{
  "status": "success",
  "data": [
    {
      "id": 42,
      "title": "Mr",
      "firstname": "Ada",
      "lastname": "Lovelace",
      "email": "ada@example.org",
      "country": "NG",
      "profilepic": null,
      "chapter_id": 9,
      "role_id": null,
      "membership_type_id": 3,
      "status": "active",
      "is_new_user": false,
      "createddate": "2026-01-15T10:00:00Z",
      "lastmodifieddate": null
    }
  ],
  "pagination": {
    "total": 1,
    "offset": 0,
    "limit": 50
  }
}
```
</ResponseExample>
