---
title: "Create Member"
api: "POST /v1/members"
description: "Create a member in the chapter."
---

Create a member in the chapter. The member starts inactive and goes through the chapter's normal onboarding; if `password` is omitted a random one is generated. Executive notifications fire as if the key's owner had created the member in the app.

**Required scope:** `members:write`

<RequestExample>
```json Request
{
  "firstname": "Ada",
  "lastname": "Lovelace",
  "email": "ada@example.org",
  "title": "Mr",
  "country": "NG"
}
```
</RequestExample>

<ResponseExample>
```json 201

}
```
</ResponseExample>
