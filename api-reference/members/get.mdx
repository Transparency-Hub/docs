---
title: "Get Member"
openapi: "GET /v1/members/{member_id}"
description: "Retrieve one member."
---

Retrieve one member. Returns `404 not_found` if the member is not in the key's chapter.

**Required scope:** `members:read`

<ResponseExample>
```json 200
{
  "status": "success",
  "data": {
    "id": 42,
    "title": "Mr",
    "firstname": "Ada",
    "lastname": "Lovelace",
    "email": "ada@example.org",
    "country": "NG",
    "profilepic": null,
    "chapter_id": 9,
    "role_id": null,
    "membership_type_id": 3,
    "status": "active",
    "is_new_user": false,
    "createddate": "2026-01-15T10:00:00Z",
    "lastmodifieddate": null
  }
}
```
</ResponseExample>
