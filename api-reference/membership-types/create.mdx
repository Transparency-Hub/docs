---
title: "Create Membership Type"
openapi: "POST /v1/membership-types"
description: "Create a membership type with the chapter default workflow, notification settings and application form, and no fees."
---

Create a membership type with the chapter default workflow, notification settings and application form, and no fees. Add fees in the app afterwards.

**Required scope:** `membership_types:write`

<RequestExample>
```json Request
{
  "name": "Gold",
  "category": "Individual",
  "description": "Full membership",
  "duration": 12,
  "renewal_timeline": 30,
  "deactivation_timeline": 60
}
```
</RequestExample>
