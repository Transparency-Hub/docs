---
title: "Create project task"
openapi: "POST /v1/projects/{project_id}/tasks"
description: "Cards on the board, ordered by column and position, each with `assignee_ids` and `label_ids`."
---

Cards on the board, ordered by column and position, each with `assignee_ids` and `label_ids`. Filter by `column_id`. Create needs a title; the key's owner must hold Projects **create** in the chapter. Assignees must be active chapter members.

**Required scope:** `projects:write`

<RequestExample>
```json Request
{
  "title": "Book venue",
  "column_id": 21,
  "priority": "high",
  "due_date": "2026-09-20T00:00:00Z",
  "assignee_ids": [
    42
  ],
  "label_ids": [
    6
  ]
}
```
</RequestExample>
