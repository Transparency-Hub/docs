---
title: "List Events"
api: "GET /v1/events"
description: "Retrieve the chapter's events, newest start first."
---

Retrieve the chapter's events, newest start first. Filter by `from` / `to` (ISO-8601 instants compared against `start_date_time`).

**Required scope:** `events:read`
