---
title: "Update Event"
api: "PATCH /v1/events/{event_id}"
description: "Update an event's details."
---

Update an event's details. Invitations are left unchanged.

**Required scope:** `events:write`

<RequestExample>
```json Request
{
  "venue": "Online",
  "meeting_link": "https://meet.example.org/agm"
}
```
</RequestExample>
