---
title: "Create Event"
openapi: "POST /v1/events"
description: "Create an event."
---

Create an event. By default every chapter member is invited (`all_participant: true`) and invitations are sent (`should_notify: true`) exactly as if the key's owner had created the event in the app.

**Required scope:** `events:write`

<RequestExample>
```json Request
{
  "title": "Annual General Meeting",
  "start_date_time": "2026-10-01T10:00:00Z",
  "end_date_time": "2026-10-01T12:00:00Z",
  "venue": "Main Hall",
  "timezone": "Africa/Lagos",
  "should_notify": true
}
```
</RequestExample>
