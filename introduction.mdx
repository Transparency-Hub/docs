# Transparency Hub Network admin web app

This guide covers the admin web app at `Staticwebsite-App` commit `b1ee213` (`origin/main`, checked September 15, 2026). Availability of each screen and action depends on your role in the selected chapter.

After sign-in, choose a chapter with an admin role. The sidebar provides **Dashboard**, **Association**, **Members**, **Transactions**, **Meetings**, **Minutes**, **Workflow**, **Settings**, and other chapter tools. Some sections, including campaigns, are feature gated and are not described here.
