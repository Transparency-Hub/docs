# Upload minutes manually

## Before you start

Select the correct chapter. You need minutes-create permission and the minutes file you intend to upload. Review the file for private information before sharing it with the chapter.

## Steps

1. Select **Minutes** in the admin sidebar.
2. Select **Upload Minutes**. If this button is unavailable, ask your chapter administrator to check your permissions.
3. Enter the details requested by the upload form and select your minutes file. Follow the file types and size limits shown by that form.
4. Submit the upload and wait for its result.
5. Return to the **Uploads** table. Open the new entry and check that the correct file and meeting details were saved.

## If it does not work

Keep the file and note the error shown on screen. Tell support whether the failure happened while selecting the file, uploading it or opening the saved entry. Do not repeatedly upload the same file while the first upload is processing.
