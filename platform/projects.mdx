# Use Projects

## Create a project

<Steps>
  <Step title="Open Projects">
    Select **Projects** in the sidebar.
  </Step>
  <Step title="Start a project">
    Select **New project**.
  </Step>
  <Step title="Enter the plan">
    Add the project name, description, start date, and due date, then select **Create project**.
  </Step>
  <Step title="Open the project">
    Select its card to open the project board.
  </Step>
  <Step title="Add and organize tasks">
    Create tasks, assign members and labels, and move cards between board columns as work progresses. Use the Board and Gantt controls to change the view when available.
  </Step>
</Steps>

## Control member access

<Steps>
  <Step title="Open General settings">
    Go to **Settings → General**.
  </Step>
  <Step title="Find Projects visibility">
    Locate the **Projects visibility** section.
  </Step>
  <Step title="Choose member access">
    Enable **Members can view all projects (read-only)** when members should see projects.
  </Step>
  <Step title="Allow volunteers if needed">
    Enable **Members can volunteer for open tasks** when members should be able to volunteer.
  </Step>
  <Step title="Save">
    Save the project visibility settings.
  </Step>
</Steps>
