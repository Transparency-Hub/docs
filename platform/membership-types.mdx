# Membership types

Open **Settings → Membership Type** to list the selected chapter's membership types. An admin with the necessary permission can create or edit a type.

The configuration flow has four steps:

1. **General Information** — Name, description, duration or end date, renewal and deactivation choices, private membership option, recurring payment option, and an application form template.
2. **Price Configuration** — Add dues and their amounts, frequencies, account mapping, and applicable tax configuration.
3. **Workflow Settings** — Set the offered approval and application fee payment rules, plus renewal approval.
4. **Notification Settings** — Choose email stages and edit supported templates for application, expiration, and renewal.

The **Automatic Recurring Payments** switch and reminder frequency controls appear in general information when relevant. Do not assume a payment retry schedule from these controls.
