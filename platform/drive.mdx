# Use Drive

## Upload and organize files

<Steps>
  <Step title="Open Drive">
    Select **Drive** in the sidebar.
  </Step>
  <Step title="Open a folder">
    Select a folder to work inside it, or stay at the top level.
  </Step>
  <Step title="Create a folder">
    Select **New Folder**, enter its name, and save.
  </Step>
  <Step title="Upload a file">
    Use the upload button and choose the file to store in the current folder.
  </Step>
  <Step title="Open the file actions">
    Use the row menu to view details, download, move, rename, share, or move an item to Trash when those actions are permitted.
  </Step>
</Steps>

## Edit a document online

<Steps>
  <Step title="Find the document">
    Open **Drive** and navigate to the document.
  </Step>
  <Step title="Open its row menu or details">
    Select **Edit online** when you have edit access. Supported documents can show **Open** when they are view-only.
  </Step>
  <Step title="Work in the editor">
    Edit or view the document in the online editor.
  </Step>
  <Step title="Return to Drive">
    Use the back control when you finish.
  </Step>
</Steps>

## Recover an item from Trash

<Steps>
  <Step title="Open Trash">
    In **Drive**, switch to the Trash view.
  </Step>
  <Step title="Find the item">
    Review the item name, deletion date, and the person who deleted it.
  </Step>
  <Step title="Restore the item">
    Use the restore action, then return to the normal Drive view.
  </Step>
</Steps>
