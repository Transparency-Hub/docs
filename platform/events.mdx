# Meetings: choose a task

Choose the task you need help with:

- [Create a meeting](/platform/create-meeting)
- [Record an external meeting](/platform/record-external-meeting)
- [Edit or cancel a meeting](/platform/edit-cancel-meeting)

These guides describe the admin web calendar. A member without meeting-management permission should ask their chapter administrator to create or change the meeting. The mobile screens may use different navigation labels; do not assume the admin web steps describe the mobile app.

**Gatherings** is a separate section for ticketed events.
