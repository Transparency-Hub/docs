# Meetings

Open **Meetings** in the admin sidebar. The page shows a monthly calendar; create a meeting from a calendar date if your chapter role permits it.

The create or edit form includes a title, start and end times, timezone, description, invitees, and a meeting location. For an online meeting you can provide an **external meeting link** (Zoom, Microsoft Teams, or Google Meet) or select a **TransparencyHub meeting** to generate an in-app link. A generated link is available after creation; the event details offer a copy action. The in-app option can include a waiting room.

For an external meeting with a link, **Record and Generate Minute** is available after a matching provider is connected under **Settings → Meeting Integrations**. Select the connected provider when recording. A bot joins the external meeting to record and transcribe it. See [Meeting Providers](/integrations/meeting-providers).

Open an existing meeting to view its details and available edit, attendance, and cancellation actions. **Gatherings** is a separate admin section for ticketed events.
