# Members

Open **Members** for the selected chapter's member table. Search or filter the list, view a member's application details, and use the available add or edit actions according to your role's member permissions.

Use **Upload Members** from the Members submenu or the button on the Members page to upload member data. The upload screen also keeps an archive of uploads. Check the import preview and results in the app before assuming that an existing record will be replaced.

Application and renewal records are in **Workflow → Application** and **Workflow → Renewal**. The admin **Settings → Application Forms** tab manages form templates used by applicants. Chapter role permissions control which member actions are available.
