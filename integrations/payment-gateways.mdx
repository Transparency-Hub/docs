# Payment setup in the admin app

Open **Settings → General** for the selected chapter. The screen includes a chapter accounts table, a **Setup Stripe Account** flow, **Connect GoCardless** for Direct Debit, and a GoCardless mandates table. Complete the connection flows presented by the app; Stripe uses account onboarding and GoCardless redirects to its authorization page.

Membership dues and payment rules are configured separately under **Settings → Membership Type**. The checkout provider and available methods depend on the chapter's payment setup and payment context.

The admin General tab does not provide fields to paste Stripe or Paystack secret keys. This guide describes only the connections and controls visible in the admin web app at the release commit.
