# Connect payment accounts

## Set up Stripe

<Steps>
  <Step title="Select the chapter">
    Confirm that you are working in the correct chapter.
  </Step>
  <Step title="Open General settings">
    Go to **Settings → General**.
  </Step>
  <Step title="Start Stripe setup">
    Select **Setup Stripe Account**.
  </Step>
  <Step title="Complete onboarding">
    Follow the Stripe account onboarding shown in the app.
  </Step>
  <Step title="Finish the setup">
    Complete the flow and return to General settings. The app confirms when the Stripe account configuration succeeds.
  </Step>
</Steps>

## Connect GoCardless

<Steps>
  <Step title="Open General settings">
    Go to **Settings → General**.
  </Step>
  <Step title="Start the connection">
    Select **Connect GoCardless**, then select **Connect with GoCardless**.
  </Step>
  <Step title="Authorize the chapter">
    Complete the authorization on GoCardless. You are returned to the admin app afterward.
  </Step>
  <Step title="Review mandates">
    Use the GoCardless mandates table in General settings to review available mandate records.
  </Step>
</Steps>

Configure dues separately under **Settings → Membership Type → Price Configuration**. The General tab does not ask you to paste Stripe or Paystack secret keys.
