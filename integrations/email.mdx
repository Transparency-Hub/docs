# Email and notification controls

Open **Settings → General** for member notification settings. When you create or edit a membership type, the **Notification Settings** step provides application, expiration, and renewal email stages and supported template controls. Recurring payment reminders are configured in the membership type's general information.

Use **Profile → Notifications** to read your own chapter notifications. This page is a paginated inbox; opening an unread entry marks it as read.

The admin web app does not expose a single global transactional email editor or a **Send Test Email** control on the Notifications page. Delivery timing and triggers depend on the configured workflow and backend service.
