# Use Elections

<Steps>
  <Step title="Open Elections">
    Select **Elections** in the sidebar.
  </Step>
  <Step title="Create an election">
    Select **New election** and complete the election form.
  </Step>
  <Step title="Find elections by stage">
    Use **Draft**, **Upcoming**, **Voting Open**, **Voting Closed**, and **Archived** to filter the list.
  </Step>
  <Step title="Open the election">
    Select an election card to manage its ballots, candidates, eligibility, and other available settings.
  </Step>
  <Step title="Share when ready">
    Use the election's copy public link action when it is ready to share.
  </Step>
</Steps>
