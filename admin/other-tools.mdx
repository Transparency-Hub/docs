# Use other admin tools

## Create a fundraising campaign

<Steps>
  <Step title="Open Fundraising">
    Select **Fundraising** in the sidebar.
  </Step>
  <Step title="Start a campaign">
    Select **Create Campaign**.
  </Step>
  <Step title="Complete and save the campaign">
    Enter the campaign information requested by the form and save.
  </Step>
  <Step title="Edit later">
    Open the campaign row menu and select **Edit**.
  </Step>
</Steps>

## Create a task

<Steps>
  <Step title="Open Task">
    Select **Task** in the sidebar.
  </Step>
  <Step title="Start the form">
    Select **Create Task**.
  </Step>
  <Step title="Enter and assign the task">
    Complete the task fields and choose the applicable assignee.
  </Step>
  <Step title="Save and track it">
    Submit the form. Use search and member filters to find assigned tasks later.
  </Step>
</Steps>

## Create a gathering

<Steps>
  <Step title="Open Gatherings">
    Select **Gatherings** in the sidebar.
  </Step>
  <Step title="Choose how to create it">
    Select **Create Gathering**, then choose **Manual Creation**. If Eventbrite is enabled, you can instead connect Eventbrite and choose **Through Eventbrite**.
  </Step>
  <Step title="Complete the gathering">
    Enter the details and save.
  </Step>
  <Step title="Review performance">
    Use the gathering table to see its date, tickets sold, revenue, and status. Select **View Details** for more information.
  </Step>
</Steps>

## Review contacts

<Steps>
  <Step title="Open Contacts">
    Select **Contacts** to see people who attempted self check-in but were not on the member list.
  </Step>
  <Step title="Export if needed">
    Select **Export CSV** to download the contacts.
  </Step>
  <Step title="Remove a contact">
    Use the delete action on a contact and confirm the dialog.
  </Step>
</Steps>

## Start an election

<Steps>
  <Step title="Open Elections">
    Select **Elections** in the sidebar.
  </Step>
  <Step title="Create the election">
    Select **New election** and complete the election form.
  </Step>
  <Step title="Manage its stage">
    Use **Draft**, **Upcoming**, **Voting Open**, **Voting Closed**, and **Archived** to find elections by state.
  </Step>
  <Step title="Share when appropriate">
    Use the election's copy public link action when the election is ready to share.
  </Step>
</Steps>

## Review the activity log

<Steps>
  <Step title="Open Activity Log">
    Select **Activity Log** in the sidebar.
  </Step>
  <Step title="Review chapter activity">
    Use the Activity Logs table to inspect recorded actions for the selected chapter.
  </Step>
</Steps>
