# Application and renewal workflows

Open **Workflow → Application** or **Workflow → Renewal** in the admin sidebar. Each screen presents stage tabs and a table of records for the selected chapter. Application stages include awaiting payment, awaiting approval, completed, and declined. Renewal stages include upcoming, awaiting payment, awaiting approval, completed, and declined.

Select a record to view its application form and available actions. The actions depend on the stage and your workflow permissions. Permitted admins can add a membership application from the application workflow screen.

The approval and payment rules are configured per membership type in **Settings → Membership Type → Workflow Settings**. That step offers switches for approval of applications, separate application fee payment, approval after payment, and approval of renewals. It is not a general step builder.
