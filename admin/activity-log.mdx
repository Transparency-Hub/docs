# Use the Activity Log

<Steps>
  <Step title="Select the chapter">
    Confirm the chapter name at the top of the sidebar.
  </Step>
  <Step title="Open Activity Log">
    Select **Activity Log** in the sidebar.
  </Step>
  <Step title="Review the table">
    Use the **Activity Logs** table to inspect recorded actions for the selected chapter.
  </Step>
  <Step title="Move through the records">
    Use the table controls to review additional activity entries.
  </Step>
</Steps>
