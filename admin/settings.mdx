# Settings

Open **Settings** in the admin sidebar. The tabs are **General**, **Membership Type**, **Meeting Integrations**, and **Application Forms**. A tab is available only when your chapter role has the relevant viewing permission.

**General** includes chapter accounts, Stripe Connect setup, GoCardless connection and mandates, directory fields, birthday broadcasts, a join slug, member notification settings, and finance visibility. Payment setup uses the flows shown here rather than a form for pasting Stripe or Paystack API keys.

**Membership Type** lists types and opens a four step configuration flow for general information, price and dues, workflow rules, and notifications. See [Membership Types](/platform/membership-types).

**Meeting Integrations** shows Google Meet, Zoom, and Microsoft Teams provider cards, plus the chapter's default recording preference. See [Meeting Providers](/integrations/meeting-providers).

**Application Forms** manages the chapter's application form templates, including a form builder. The sidebar also exposes **Roles** and **Executives** under Settings as separate pages.
