# Use chapter settings

<Steps>
  <Step title="Select the chapter">
    Confirm the chapter name at the top of the sidebar.
  </Step>
  <Step title="Open Settings">
    Select **Settings** in the sidebar.
  </Step>
  <Step title="Choose a tab">
    Use **General**, **Membership Type**, **Meeting Integrations**, or **Application Forms**. A tab appears only when your role can view it.
  </Step>
</Steps>

## General

Use this tab to manage chapter accounts, Stripe and GoCardless connections, GoCardless mandates, directory fields, birthday broadcasts, the chapter join link, member notifications, finance visibility, and member access to Projects.

## Membership Type

Use this tab to create and edit membership types. Complete all four steps: **General Information**, **Price Configuration**, **Workflow Settings**, and **Notification Settings**.

## Meeting Integrations

Use this tab to connect Google Meet, Zoom, or Microsoft Teams. After connecting a provider, you can set whether recording is enabled by default for new external meetings.

## Application Forms

Use this tab to create, view, and edit application form templates. Assign the desired template while configuring a membership type.

<Info>
  **Roles** and **Executives** appear as separate pages beneath Settings in the sidebar.
</Info>
