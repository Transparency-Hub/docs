# Use Gatherings

## Create a gathering manually

<Steps>
  <Step title="Open Gatherings">
    Select **Gatherings** in the sidebar.
  </Step>
  <Step title="Choose Manual Creation">
    Select **Create Gathering**, then choose **Manual Creation**.
  </Step>
  <Step title="Enter the details">
    Complete the gathering form and save.
  </Step>
  <Step title="Review the gathering">
    Use the table to see its date, tickets sold, revenue, and status. Select **View Details** for more information.
  </Step>
</Steps>

## Use Eventbrite when enabled

<Steps>
  <Step title="Connect Eventbrite">
    Select **Connect Eventbrite** and complete the connection.
  </Step>
  <Step title="Create on Eventbrite">
    Select **Create Gathering → Through Eventbrite** to open Eventbrite's creation page.
  </Step>
  <Step title="Sync gatherings">
    Return to the admin app and select **Sync from Eventbrite**.
  </Step>
  <Step title="Open the public page">
    Use **Visit Page** beside an Eventbrite gathering when you need to view its public listing.
  </Step>
</Steps>
