# Dashboard

Open **Dashboard** after choosing a chapter. The main page shows a workflow application chart, a chapter admins card, an all members table, contributions, and a world map. You can choose a date range and a daily, weekly, monthly, or yearly chart cadence; selecting a workflow bar opens the corresponding application records.

The sidebar has separate **Finance**, **Fundraising**, **Membership**, and **Meetings** dashboard pages. Each requires its own viewing permission. The main dashboard also checks chapter viewing permission.

Use **Members** for the full member table, **Transactions** for financial records, and **Workflow → Application** to review applications. The dashboard is an overview of the selected chapter rather than a configurable association-wide analytics report.
