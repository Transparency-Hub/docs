# Notifications

Open **Profile → Notifications** in the admin sidebar to see a paginated list of notifications for your account in the selected chapter. Select an item to read its content; unread items are marked as read when opened.

Notification configuration is elsewhere in **Settings**. The **General** tab includes member notification settings. The **Membership Type** creation or editing flow has a **Notification Settings** step for application, expiration, and renewal email stages, with a template modal for each supported stage.

The Notifications page is an inbox. It does not provide a global email template editor, test email action, or switches for every notification type.
