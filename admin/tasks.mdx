# Use Tasks

<Steps>
  <Step title="Open Task">
    Select **Task** in the sidebar.
  </Step>
  <Step title="Start the form">
    Select **Create Task**.
  </Step>
  <Step title="Enter and assign the task">
    Complete the task fields and choose the applicable assignee.
  </Step>
  <Step title="Save the task">
    Submit the form and confirm that it appears in the task list.
  </Step>
  <Step title="Find it later">
    Use the search field and member filter to narrow the assigned tasks.
  </Step>
  <Step title="Edit when needed">
    Use the task's edit action, update the details, and save.
  </Step>
</Steps>
