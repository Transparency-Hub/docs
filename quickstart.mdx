# Getting started

1. To sign up a new association, go to the [Transparency Hub Network website sign-up form](https://transparencyhubnetwork.ai/#signup). Submit your association details there; the team will follow up to set up your account and trial. The admin web app does not create a new association account.
2. Once your admin access is ready, sign in to the web app and select a chapter where you have an assigned admin role. The selection determines the data and permissions shown in the admin area.
3. Open **Dashboard** for the selected chapter. Use the membership, finance, fundraising, and meetings dashboard links according to your permissions.
4. Open **Settings → Membership Type** to view or create a membership type. Its four steps are **General Information**, **Price Configuration**, **Workflow Settings**, and **Notification Settings**.
5. Open **Members** to add a member or **Upload Members** for a file import. Application and renewal records are under **Workflow → Application** and **Workflow → Renewal**.
6. Open **Meetings** to schedule a meeting. To record an external meeting, first connect its provider under **Settings → Meeting Integrations**.

<Info>
  Controls can be hidden or disabled when your chapter role lacks the corresponding permission.
</Info>
