# Getting started

1. Sign in to the web app and select a chapter where you have an assigned admin role. The selection determines the data and permissions shown in the admin area.
2. Open **Dashboard** for the selected chapter. Use the membership, finance, fundraising, and meetings dashboard links according to your permissions.
3. Open **Settings → Membership Type** to view or create a membership type. Its four steps are **General Information**, **Price Configuration**, **Workflow Settings**, and **Notification Settings**.
4. Open **Members** to add a member or **Upload Members** for a file import. Application and renewal records are under **Workflow → Application** and **Workflow → Renewal**.
5. Open **Meetings** to schedule a meeting. To record an external meeting, first connect its provider under **Settings → Meeting Integrations**.

<Info>
  Controls can be hidden or disabled when your chapter role lacks the corresponding permission.
</Info>
